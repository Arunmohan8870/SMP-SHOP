# Arunpandi M – Frontend Developer Assignment

This project is a Visual Page Hierarchy Editor built using **React**, **React Flow**, **Dagre**, **DndKit**, and **TailwindCSS**. It allows users to add, reorder, edit, and persist layout sections visually with export functionality.

---

## 🚀 Features Implemented

- ✅ Visual drag-and-drop editor using React Flow + Dagre
- ✅ Auto-layout adjustment using Dagre
- ✅ Reordering sections with DndKit
- ✅ Edit and delete nodes
- ✅ Persistent state using `localStorage`
- ✅ Export layout as JSON
- ✅ Upload video intro (for each section or node)

---

## 🧪 Tech Stack

- React + TypeScript
- TailwindCSS
- React Flow
- DndKit
- Dagre
- localStorage
- Vite
